## Goal

把当前按章节分块的一页式 Portfolio 重构为一张持续向下延伸的纯黑数字画布。招聘方只需自然向下滚动，就能跟随像素 Winston 经过经历、项目、能力、联系和 AI 对话节点，理解 Winston 作为 AI 产品经理如何把模糊问题变成可用产品。

本轮优先验证桌面端空间架构、视觉叙事和滚动手感。具体经历与项目文案后续替换，不阻塞架构实现。

## Confirmed Facts

- 项目使用 Next.js 16.2.3、React 19、Tailwind 4 和手写 CSS；开发前必须阅读 `node_modules/next/dist/docs/` 中与实际改动相关的指南。
- 当前首页包含 Hero、Work、两个 Projects、Skills、Contact、Ask Winston 和 Footer，并已有锚点导航、项目滚动逻辑、像素头像与聊天原型。
- 当前主题色为荧光绿 `#6EE7B7` 与紫色 `#A78BFA`，本轮继续使用；背景保持纯黑。
- 现有 `/api/chat` 提供流式聊天能力，旧 `/ask-zoo` 路由暂时保留。
- Work、项目、Skills 与联系信息仍包含 mock 或待替换内容，本轮允许继续使用占位数据。
- 用户提供的 KUMALEON 截图只作为连续纵向叙事、超大排版、结构化网格、几何元素和内容锚点参考，不复制 Character 内容或具体资产。
- 本轮不做完整移动端适配，以 1440 × 900 为主要设计基准，同时保证 1280px 宽桌面可浏览。

## Requirements

### Continuous Canvas

- 页面是一张从 Hero 向下延伸的画布，不是多个接近整屏的 Section 依次堆叠。
- 7 个主节点：Hero、Work、mewmo、Ask Winston Project、Skills、Contact、Ask Winston Chat。
- Work 内含 3 个经历微节点；Skills 的 5 项能力属于同一个组合节点。
- 节点自由错落但共享隐形网格、阅读方向和安全边距，预计约 10-12 个桌面视口高。
- 核心内容采用滚动即阅读，不依赖 click、hover 或展开才能理解主线。

### Winston Visual Object

- 沿用现有像素 Winston，保留脸部识别特征与绿色、紫色特征，可重新整理像素比例和模块结构。
- Hero 中，超大 WINSTON 与像素 Winston 共同构成一级视觉。
- Winston 大部分时间保留在视口中，节点切换时移动到新的构图位置并完成明确重组。
- Winston 可以连接、圈选、托起或拆解内容；只保留少量观察、思考、确认、在线状态。
- 首版仅使用二维 SVG/CSS 像素模块与 transform/opacity，不使用复杂 3D、粒子系统或逐帧视频。
- 先制作 Hero 到 Work 第一个微节点的短滚动原型，验证后再扩展整页。

### Background

- 背景始终纯黑，不按 Scene 更换大面积色彩。
- 使用局部细网格、轨迹线、节点、扫描框和少量绿色/紫色像素模块。
- 网格部分区域明显、部分区域退隐；滚动时缓慢视差、轨迹绘制、节点点亮。
- 不使用模糊渐变、霓虹光晕、随机粒子或大面积漂浮装饰作为主背景。
- 绿色表达行动、当前焦点、确认；紫色表达思考、过渡、次级信息。仅扩展透明度和少量明暗层级。

### Navigation

- Hero 首屏显示完整章节目录。
- 离开 Hero 后收缩为左侧纵向节点轨迹，只显示当前节点名称，其余以点表示。
- 返回 Hero 时恢复完整形态；两种形态共享 anchor 数据和 active node，不造成布局跳动。

### Containers and Content

- 普通标题、经历、能力、正文直接落在画布上，以位置、字号、留白和轨迹建立层级。
- 真实项目截图、Ask Winston 对话窗口和少数重点内容才使用直角细边框、扫描框或窗口容器。
- 不使用泛滥卡片、等宽三列、表格或每节点完整边框。
- 所有主线信息无需点击或 hover 即可阅读；hover 只提供反馈。

### Nodes

- Hero 在首屏表达 WINSTON、AI 产品经理定位、核心主张和像素 Winston，并建立整页视觉规则。
- Work 是一条轨迹经过 3 个经历停靠点；每点直接显示公司、岗位、时间、摘要和必要证据。
- mewmo 使用真实产品截图作为一级视觉；缺失时使用明确标记的直角占位框，不继续使用虚构 Signal Desk 界面。
- Ask Winston Project 只解释产品动机与判断，不重复完整聊天窗口。
- Skills 是 5 个大型能力词组成的组合节点，Tools/Methods 为次级文字，不使用表格、百分比、雷达图或 Logo 墙。
- Contact 只保留 Email、GitHub、微信等直接入口；本轮移除不可真实发送的表单，不实现 Resend。
- Ask Winston 是最终交互高潮：Winston 移入头像位，对话窗口从它周围展开，约占视口 70%，保留现有聊天能力；窗口可短暂 sticky，但不强迫用户聊天才能离开。
- Ask Winston 后只保留极简版权与 Back to top。

### Cursor, Type and Accessibility

- 自定义光标改为克制像素准星/圈选工具，不保留高存在感紫色圆球和 GO 标签；光标层不得截获事件。
- 保留 Albert Sans 与 Noto Sans SC 作为正文基础，英文展示字可更换为本地自托管字体。
- 超大文字重点用于 Hero、Work 和两个项目标题，不机械复制到每个节点。
- reduced-motion 下关闭连续变形、视差和复杂移动，只保留静态 Winston、节点内容和必要淡入。
- 本轮不设计完整移动端布局和动画，但小屏不应彻底不可读；键盘可访问核心内容和聊天。

- [ ] AC05：背景始终纯黑，绿色与紫色保持现有主题语义，网格/轨迹不干扰正文。

- [ ] AC08：Work 不再是列表+详情面板，Projects 不再是整屏覆盖卡片，Skills 不再是表格。
- [ ] AC09：mewmo 不展示虚构 Signal Desk；缺图时使用明确占位。
- [ ] AC10：Ask Winston Project 与最终聊天职责不同。

## Out of Scope

- 完整移动端视觉设计、移动端专属节点重排和动画。
- 重写真实经历、项目、Skills 和联系信息。
- 新建项目详情路由或改变公开 URL。
- Contact 邮件表单、Resend、验证码和表单限流。
- 复杂 3D、WebGL、粒子、逐帧视频和滚动劫持。
- 复制 KUMALEON 的 Character 内容、品牌资产或具体图形。
- 删除旧页面、合并远端分支或发布上线。

## Key Decisions

- 设计模式：保留信息架构与核心内容，重构首页视觉空间。
- 主题：纯黑画布 + 现有荧光绿与紫色 + 像素 Winston。
- 叙事：Winston 从个人像素角色逐渐成为可交互 AI 分身，并把分散信息组织成产品证据。
- 镜头：Winston 大部分时间留在视口内，在节点切换时换位和重组。
- 内容：滚动即阅读，不以点击探索作为理解前提。
- 粒度：7 个主节点，Work/Skills 使用微节点或组合节点。
- 导航：首屏完整，滚动后收缩为左侧节点轨迹。
- 容器：文字直接落在画布上，真实产品与聊天等内容使用边框容器。
- 项目资产：真实截图优先，缺失时诚实占位。
- Contact：直接联系方式，不做表单。
- 终场：Winston 进入约 70% 视口的聊天窗口，之后极简 Footer。

## Risks and Deferred Items

- Winston 变形质量是最大风险，必须通过 Hero 到 Work 短原型先行验证。
- 真实截图、最终文案、联系方式和英文展示字体后续补齐。
- 当前任务已有旧架构实现，实施时逐段替换，避免聊天与导航回退。
- 完整移动端适配另做独立任务。
